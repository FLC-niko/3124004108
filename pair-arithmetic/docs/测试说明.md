# 测试说明

运行命令：

```bash
bash scripts/test.sh
```

测试使用一个很小的反射测试器，不依赖 JUnit 或网络下载。目前共 21 项，主要用例如下：

| 编号 | 测试内容 | 预期 |
| ---: | --- | --- |
| 1 | `4/8` 约分 | 输出 `1/2` |
| 2 | `19/8` 格式化 | 输出 `2’3/8` |
| 3 | 普通单引号带分数解析 | `2'3/8` 等于 `19/8` |
| 4 | `1/6 + 1/8` | 精确得到 `7/24` |
| 5 | `2 + 3` 与 `3 + 2` | 等价键相同 |
| 6 | `3 − 2` 与 `2 − 3` | 等价键不同 |
| 7 | 题目给出的嵌套加法例子 | 正确判重 |
| 8 | 两棵不同左结合树 | 不误判为重复 |
| 9 | 除法右侧乘法 | 输出必要括号 |
| 10 | 随机生成 500 题 | 不出现交换等价重复 |
| 11 | 随机生成 300 题 | 每题最多 3 个运算符 |
| 12 | 递归检查所有减法节点 | 中间结果不为负数 |
| 13 | 递归检查所有除法节点 | 结果均为真分数 |
| 14 | `-r 1` | 能生成默认 10 题 |
| 15 | 带分数和乘法优先级 | 解析结果正确 |
| 16 | 括号优先级 | 解析结果正确 |
| 17 | 对、错、非法答案混合批改 | 分类和格式正确 |
| 18 | 答案缺失 | 记为 Wrong |
| 19 | 命令行生成 12 题 | 两个文件均为 12 行 |
| 20 | 缺少 `-r` | 返回错误并显示帮助 |
| 21 | 生成 50 题后回读批改 | Correct 50，Wrong 0 |

另外执行：

```bash
bash scripts/stress-test.sh
```

会生成 10,000 道题并递归复查全部约束，再写入文件并用自己的批改模块回读。最近一次真实结果保存在 `performance/stress-test-result.txt`：10,000 道题全部唯一，Correct 10,000、Wrong 0。
