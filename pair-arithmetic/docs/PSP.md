# PSP2.1

预估耗时是在编码前按任务规模拆分的计划。实际耗时必须由两位成员根据各自记录核对，仓库不替成员编造；提交博客前请填写最后一列并重新计算合计。

| PSP2.1 | Personal Software Process Stages | 预估耗时（分钟） | 实际耗时（分钟） |
| --- | --- | ---: | ---: |
| Planning | 计划 | 30 | 待两人核对 |
| · Estimate | · 估计任务需要多少时间 | 20 | 待两人核对 |
| · Analysis | · 需求分析（包括学习新技术） | 90 | 待两人核对 |
| · Design Spec | · 生成设计文档 | 60 | 待两人核对 |
| · Design Review | · 设计复审 | 30 | 待两人核对 |
| · Coding Standard | · 制定代码规范 | 20 | 待两人核对 |
| · Design | · 具体设计 | 90 | 待两人核对 |
| · Coding | · 具体编码 | 300 | 待两人核对 |
| · Code Review | · 代码复审 | 60 | 待两人核对 |
| · Test | · 测试、修改和提交 | 180 | 待两人核对 |
| Reporting | 报告 | 0 | 0 |
| · Test Report | · 测试报告 | 60 | 待两人核对 |
| · Size Measurement | · 计算工作量 | 20 | 待两人核对 |
| · Postmortem & Process Improvement Plan | · 事后总结与改进计划 | 60 | 待两人核对 |
| **合计** |  | **1020** | **待两人核对** |
